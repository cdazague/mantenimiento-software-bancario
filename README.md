# Mantenimiento de Software Bancario

Prototipo académico de un canal digital bancario inspirado visualmente en servicios de banca en línea. No es un producto oficial de BBVA Colombia ni realiza operaciones financieras reales.

## Tecnologías
- HTML5: estructura.
- CSS3: diseño adaptable a computadores y celulares.
- JavaScript: interacción y validaciones.
- GitHub Pages: publicación gratuita.

## Funcionalidades
1. Inicio de sesión simulado.
2. Consulta de saldo de demostración.
3. Transferencias ficticias con validación de saldo.
4. Pago ficticio de servicios.
5. Historial de movimientos de la sesión.

## Cómo ejecutar
Abre `index.html` en un navegador o abre la carpeta en Visual Studio Code y utiliza una extensión de servidor local.

## Publicación con GitHub Pages
1. Sube todos los archivos del proyecto a un repositorio de GitHub.
2. Entra al repositorio y abre **Settings**.
3. Selecciona **Pages** en el menú.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Pulsa **Save** y espera a que GitHub genere el enlace público.

## Aviso
Este proyecto es exclusivamente demostrativo. No ingreses contraseñas reales, números de cuenta reales ni información personal.
